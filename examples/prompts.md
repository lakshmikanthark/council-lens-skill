# Example prompts

## Product and business

```text
Council this: should we launch a free tier or a 14-day trial?
```

```text
War-room this pricing change. Use current competitor pricing only if it can change the recommendation.
```

```text
Red-team this go-to-market plan and give me the smallest experiment that could invalidate it.
```

## Career

```text
I am torn between these two roles. Run a Council Lens using learning, role fit, compensation, brand, mobility and downside.
```

## Engineering

```text
Pressure-test whether this service should stay a monolith or move to microservices this quarter.
```

```text
Deep council this architecture using the attached design doc. Treat migration risk and rollback as first-class constraints.
```

## Purchases and commitments

```text
Council whether I should buy this now or wait six months. Separate current price/spec facts from my assumptions.
```

## Anti-confirmation bias

```text
I strongly prefer Option A. Council it anyway and build the strongest evidence-based case against my preference before synthesizing.
```

## Deep evidence mode

```text
Deep council this acquisition decision using the attached financial model and current market facts. Tell me what evidence would flip the answer.
```
