# Changelog

## 2.0.0 — 2026-09-29

- Renamed the public project and Skill to **Council Lens** for clearer independent branding.
- Reimplemented the council protocol with five separated lenses, evidence audit, blind challenge, dominant-constraint handling and experiment-before-commitment logic.
- Added anti-confirmation-bias handling and one optional specialist lens for Deep mode.
- Split runtime instructions into a compact Skill control plane plus progressive references.
- Added political, high-stakes, privacy, external-action and multi-agent-claim guardrails.
- Added behavioral evaluation cases and contract tests.
- Added deterministic packaging, repository validation, adversarial negative controls and GitHub Actions.
- Adopted Apache License 2.0 for this repository's original implementation and documentation.
- Added explicit third-party attribution and license-boundary documentation; no upstream source files are included.

## 1.x historical note

Earlier local prototypes used the working title "LLM Council Skill" and an all-rights-reserved release posture. Version 2.0.0 supersedes those prototypes with distinct branding, independent implementation and a standard open-source license.
